# Flix Hub

قناتنا: https://t.me/YOUR_CHANNEL

## النشر على Heroku

1. اعمل Fork لهذا المستودع.
2. افتح الرابط التالي بعد استبدال `USERNAME` باسم حسابك على GitHub:

   `https://dashboard.heroku.com/new?template=https://github.com/USERNAME/A2`

3. املأ المتغيرات المطلوبة (`APP_ID` و`API_HASH` و`STRING_SESSION` و`TG_BOT_TOKEN` وغيرها) ثم اضغط Deploy.

لإنشاء `STRING_SESSION` شغّل `python3 stringsetup.py` على جهازك.
